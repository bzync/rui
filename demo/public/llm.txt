# @bzync/rui

> Composable React UI components with scoped, customizable light and dark themes. `@bzync/rui`
> is an open-source React + Tailwind CSS component library published to npm, shipping ESM and
> CJS builds with TypeScript types. Components expose native semantics and keyboard behavior,
> accept `className` and native element props, and honor reduced-motion preferences.

Key facts:

- Package: `@bzync/rui` (npm)
- Install: `npm install @bzync/rui framer-motion`
- Stylesheet: import `@bzync/rui/styles.css` once near the app root
- Imports: root export (`@bzync/rui`) or subpath (`@bzync/rui/button`) for tree-shaking
- React support: 18.2 and 19
- Theming: `ThemeProvider` (controlled/uncontrolled, system preference, persistent selection,
  scoped themes, custom accent/neutral scales, any CSS variable via `tokens`), `ThemeToggle`,
  `useTheme()`
- Repository: https://github.com/bzync/rui
- Documentation: https://rui.bzync.com
- License: ISC
